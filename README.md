## Repository contents

- `index.html` and `styles.css`: the GitHub Pages site.
- `evidence/installed-client.json`: machine-readable public evidence.
- `scripts/backup-client-from-adb.sh`: personal off-device backup helper.
- `CAPTURE_PLAYER_STATE.md`: consent-aware player-state and experience checklist.
- `docs/RIGHTS_AND_DEMO.md`: route toward an authorized educational demonstration.

## Contribution boundary

Welcome:

- source-linked release and shutdown history;
- original testimony and captures you are authorized to share;
- accessibility and interface documentation;
- regional chronology;
- preservation methodology and corrections.

Do not submit:

- APKs, OBBs, extracted commercial assets or proprietary server code;
- passwords, tokens, account databases, payment records or private chat;
- circumvention tooling;
- material you do not have the right to publish.
