# Player-state capture checklist

Do this while the official service still works. Prefer the phone's built-in screenshot and screen-recording tools. Keep private captures private.

## Identity and service

- [ ] Region and server name
- [ ] Character name and public player ID
- [ ] House, dorm and club/guild
- [ ] Account-linking methods, recorded by provider name only — never record passwords or tokens
- [ ] Current app version shown in the game
- [ ] Support/contact and privacy-export pages

## Progress

- [ ] Story chapter and completed year
- [ ] Character level and key progression screens
- [ ] Card collection, card levels and favorite decks
- [ ] Echoes, companions, cosmetics, wand, owl and broom
- [ ] Achievements, seasonal history and rankings
- [ ] Friends list and club roster, with other players' consent before public sharing
- [ ] Purchase history through the store provider, kept private

## Cultural and gameplay record

- [ ] First launch and login flow without exposing credentials
- [ ] Character creation and sorting
- [ ] Hogwarts exploration and moving staircases
- [ ] Classes and tutorials
- [ ] A representative duel and practice match
- [ ] Forbidden Forest or current equivalent activity
- [ ] Dorm/social-space interaction
- [ ] Seasonal event and live-service menus
- [ ] Settings, controls, accessibility and localization
- [ ] Music, ambient audio and voice presentation
- [ ] Connection-loss and reconnect behavior

## File handling

- [ ] Copy captures off-device
- [ ] Preserve original filenames and timestamps
- [ ] Generate SHA-256 checksums
- [ ] Keep an unedited master and separate edited/shareable copies
- [ ] Redact account IDs, real names, chat and payment information before publication
